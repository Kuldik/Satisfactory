**Демо:** [satisfactory-one.vercel.app](https://satisfactory-one.vercel.app/)

---

## О проекте

Игра задумана как **однопользовательская** сессия в полноэкранном canvas: поверх Three.js лежит React-интерфейс (HUD, меню строительства). Ядро — класс `Engine` с игровым циклом на `requestAnimationFrame` и **фиксированным шагом симуляции** для будущих систем (производство, энергия, конвейеры).

Сейчас проект на стадии **прототипа**: хорошо проработаны рендер, камера, ввод, размещение составных зданий по JSON-паттернам и **dev-панель** для ручной сборки сцен из отдельных моделей; полная симуляция цепочек и сохранение всего мира ещё в работе.

### Долгострой

Чтобы не терять нить через месяцы и годы, в репозитории ведутся отдельные файлы:

## Возможности

- **3D-мир** — загрузка ассетов из папки `kits/` (Kenney и др.), отображение сетки и этажей.
- **Строительство из меню** — выбор здания с зарегистрированным паттерном (например майнеры, водокачка) и размещение **целого набора** как одной конструкции.
- **Режим разработчика** — панель с выбором частей, линейное/точечное размещение, масштаб, демонтаж, экспорт и импорт композиции в JSON.
- **Данные в духе Satisfactory** — типы ресурсов, зданий, рецептов; парсер экспорта **Docs.json** из игры для подготовки контента.
- **Автосохранение** — каркас сохранений (время игры, камера и т.д.); сериализация сущностей ECS запланирована.

## Запуск локально

Требуется **Node.js** (рекомендуется актуальный LTS).

```bash
cd game
npm install
npm run dev
```

Сборка: `npm run build` — перед ней скрипт `prebuild` создаёт связь `public/kits` → `../kits` (на Windows — junction), чтобы статика подтягивала модели.

Просмотр прод-сборки: `npm run preview`.
