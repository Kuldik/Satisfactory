## [0.1.0] — 2026-03-31

Первая зафиксированная «база» прототипа (долгострой).

### Добавлено

- Приложение `game/`: React 19, TypeScript, Vite 6, Three.js.
- Игровой цикл `Engine`: рендер каждый кадр, фиксированный тик, автосейв (каркас данных).
- Сцена: камера, сетка, этажи, загрузка моделей из `kits/` (symlink/junction в `public/kits` при сборке).
- HUD, меню строительства, паттерны зданий (JSON), dev-панель для сборки сцен и экспорта/импорта композиций.
- Задел ECS (bitecs): компоненты и заготовки систем; парсер экспорта Satisfactory `Docs.json` для контента.
- Корневой `README`, дорожная карта и этот changelog.
