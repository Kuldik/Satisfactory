# Дорожная карта

Документ для **долгостроя**: фиксирует направление, этапы и необязательные идеи.

---

## Зачем этот проект

Собрать в браузере **узнаваемый factory-builder** (сетка, 3D, строительство, цепочки производства) без претензии на клон 1:1 оригинальной игры. Упор: читаемый код, модульность, ECS как основа симуляции.

---

## Текущая база (что уже есть)

- React 19 + Vite 6 + Three.js; `App.tsx` разгружен в хуки (`useGameEngine`, `useBuilderKeyboard`, `useThemeHotkey`, …).
- `Engine` с фиксированным тиком и автосейвом. **Симуляция фазы 1 запущена**: `Engine.tick()` гоняет ECS через `sim/SimulationManager` — добыча, переплавка, энергобаланс, блэкаут; поток предметов через глобальный склад (без конвейеров).
- Рендер сцены, орбитальная камера + **WASD**, сетка, этажи, загрузка GLB/OBJ из `kits/`.
- Меню строительства (Q) + две системы постановки: **префабы** (одиночные GLB) и **паттерны** (JSON-композиции). Паттерны: майнеры Mk1–3, вода/нефть/нагнетатель/скважина, плавильня/литейная/лесопилка, биогенератор, инопланетный, столбы/ЛЭП, декор.
- **Логистика-билдеры**: конвейеры Mk1–6 и **трубы** (фаза труб завершена) — процедурные линии, снап, превью. **Железная дорога — в активной разработке** (рельсы/колено, подвижной состав, станция; итерация `geo8`).
- **Снос**: одиночный + удержание для композитов (анимация) + мультиселект.
- Энергоздания (визуально): APA, ЛЭП, столбы, накопитель.
- Светлая/тёмная **тема** с перекраской вручную собранных префабов.
- Dev-конструктор (admin-панель): части китов, линия/точка, экспорт/импорт композиции. `IS_DEV = true` — доступ всем (временно).
- bitECS: компоненты **активны** через `sim/`. Старые `systems/*` и парсер `Docs.json` пока не задействованы (sim использует свой мини-каталог).
- Сохранение: визуальный мир — `localStorage` (на каждое размещение); игровое состояние (склад/время) — `SaveData`/IndexedDB (5 слотов + checksum), загрузка на старте.

## Ледник (идеи без срока)

- Мультиплеер — только если явно понадобится; по умолчанию вне скоупа.
- Импорт сейвов из Satisfactory — нереалистично; не планировать.

---

## Принципы разработки

1. **Сначала симуляция, потом визуальный шум** — чтобы не упереться в переписывание.
2. **Один источник правды** — состояние игры в ECS/движке, React только отображает и шлёт команды.
3. **Маленькие интеграции** — каждый PR/шаг должен оставлять проект в запускаемом состоянии.
4. **Документы жить вместе с кодом** — крупное решение (формат сейва, протокол сети) — короткая заметка в этом файле или в `game/README.md`.
